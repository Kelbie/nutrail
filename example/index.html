My Cool Static Site

Pretend this is a private tracker, a blog, or any static page hosted on GitHub Pages. There is no backend here — just plain HTML. The donate button floating bottom-right (and the inline card below) are served by a nutrail instance on Railway.

The whole integration is this one line:

<script src="https://nutrail-production.up.railway.app/donate/widget.js" defer></script>
